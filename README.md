# 안녕하세요, wong2kim입니다

제조 현장에서 10년 일한 엔지니어이고, 지금은 회사 AX전략팀에서 기획을 맡고 있습니다. AI 코딩 에이전트(Claude Code, Codex)로 필요한 도구를 직접 만들고 있습니다.

## 일하는 방식

- **문제를 정의하고(PRD), AI 에이전트로 빠르게 구현하고, 직접 써 보며 검증**합니다.
- "이게 현장에서 실제로 쓸 만한가"를 판단하고, 테스트와 실사용으로 확인하는 데 집중합니다.
- 설비·공정·생산 데이터처럼 제조 현장 문제를 AI로 푸는 일에 관심이 많습니다.
